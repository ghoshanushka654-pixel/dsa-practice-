# 🧠 DSA Practice (Python)

All my Data Structures & Algorithms practice in one place, organised by my course modules.
Every file is a standalone Python program with a header (topic, source, difficulty, approach,
time/space complexity) and built-in `assert` tests.

## ▶️ Run everything

```bash
python run_all.py          # runs all solutions and prints PASS / FAIL
python 04-trees/bst.py     # or run a single file
```
